# Fitflix product requirements

Adult wellness tracking centered on Indian food habits: authenticated onboarding; preferences and editable goals; source-attributed food search; meal CRUD with immutable nutrient snapshots; household gram conversions; reusable thalis and regional/hostel meal estimates; water and weight; BMI with limitations; experience/equipment-based workout scheduling and completion; actual-record progress and weekly insights.

Use off-white, white, deep green and mint surfaces with restrained warm accents. Provide desktop navigation and five-destination mobile bottom navigation, keyboard focus, labeled forms, empty/error/loading states, and reduced motion. Normal flows use the real API and persisted records. No fictional user activity or invented nutrient values.

Preserve the existing modular monolith, data import and account privacy workflows. Java 21, React/TypeScript, PostgreSQL/Flyway, one-origin reverse proxy and container/CI deployment preparation. Public deployment and spending remain unauthorized. Email verification, live email delivery, backup restoration, hosting and production monitoring require independently verified integrations before release.
